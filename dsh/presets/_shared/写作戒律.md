# 写作戒律（反模板 + 去 AI 味）—— 所有 Agent 通用，单一来源

> 本文件由 `dsh/run-agent.sh` 在每次运行时自动注入任务指令，所有 Agent（含未来新增）一律遵守。
> 改动此一份，全站生效；不要在单个 Agent 预设里另写一套。

## 一、反模板（结构多样，不套同一个骨架）

- **严禁每篇都用「我的判断」作结尾标签或收束小标题。** 观点应融入行文，或用一句自然的话点题，不依赖固定套路。
- **结构因题制宜**，不得套用同一骨架（如"三段小标题 + 结尾亮观点"）。可据内容选用：
  叙事钩子 / 今昔对比 / 时间线 / 层层递进 / 问答 / 留白 / 一个反例开场。
- **不必给每个论点都编号 1/2/3**；能用自然段落说清的，不强行罗列。
- **结尾多样**：一句点睛、呼应开头的钩子、一段留白、把判断藏在某段话里，都比单独的"我的判断"更有章法。
- 小标题可以口语化、带情绪，不必工整对称成"名词+动词+名词"的 PPT 腔。

## 二、去 AI 味（写作时就规避，不是写完了再改）

下笔前逐条自检，命中即换写法：

1. **禁空泛套话开场**：不用「在当今……背景下」「随着……不断发展」「近年来……日益……」「在……时代」铺垫。开场直接上场景 / 冲突 / 反例。
2. **禁机械总结词**：不用「值得注意的是」「总而言之」「综上所述」「毋庸置疑」「显而易见」。
3. **禁万能排比**：不用「首先……其次……最后」「一方面……另一方面」「不仅……更……还」的对称堆砌。
4. **禁说教口吻**：不用「让我们……」「我们需要……」「我们应该……」。
5. **禁过度框架词**：不用「正如 X 所说」「正如前文所述」机械堆「——」「：」。
6. **禁教科书定义**：不用「所谓 A，是指……」「A，又称 B，是一种……」。
7. **禁病态匀称**：每段长度别几乎一致、句式别高度对仗；故意写几个短到一两字的句子，长短错落。
8. **禁正确的废话**：删掉放之四海皆准却无信息量的句子（"坚持很重要""好故事需要好人物"）。
9. **禁无细节的抒情**：堆形容词（"非常精彩""令人动容"）不如给具体人名 / 书名 / 场景 / 数据。
10. **禁过度工整小标题**：见"反模板"末条。

## 三、写成"活人味"的硬标准

- **有态度、有细节、有长短、没套话。** 宁可有点刺，也别正确得无聊。
- 用具体代替抽象：说"读者会不自觉代入、半夜还惦记主角下一步"胜过"提升代入感"。
- 可以给一点个人语气（呢 / 吧 / 啊、一点偏激或怀疑），比完美排比更像人。
- 至少一处真实具体的人名 / 书名 / 案例 / 数据，不泛泛而谈。
- 结尾别"总之"，用一句带刺或带温度的真心话收，让事实自己收尾，不喊口号。

## 四、终检（成文前逐条过，全过才交稿）

- [ ] 没有出现「我的判断」作固定结尾标签
- [ ] 没有「在当今 / 随着 / 值得注意的是 / 总而言之 / 首先其次最后 / 让我们」
- [ ] 至少有一处具体真实的人名 / 书名 / 案例 / 数据
- [ ] 长短句混用，段落长度有变化
- [ ] 读起来像一个人坐在对面聊，不像一篇科普总结或营销稿
