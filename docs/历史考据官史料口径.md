# 历史考据官 · 史料口径（X4 决策 · 已拍板并落地）

> 文档定位：AI 圈 v3「历史考据官」Agent 的**史料引用口径权威依据**（ROADMAP X4）。
> 作用：① 明确"哪些来源合格 / 哪些待核 / 哪些禁用"；② 规定"存疑如何处理"；
>       ③ 把口径同时落到 `historian` preset 的硬约束与未来百家学院 MCP 知识库检索策略上。
> 拍板时间：2026-08-15（萧哥）。本文件取代此前"X4 沿用 preset 现状、不再成文"的临时记录。
> 机制与数据锚点详见 `百家学院数据接线实测.md`（§5/§6/§7）。

---

## 0. 一句话总纲

**无源不立论、无据不断言。** 一手精校 > 一手可读 > 二手待核；存疑必明说、出处必标、置信度必填。
宁可少写、标疑，不可强作定论、把传言当史实。

---

## 1. 来源分级（Tier）—— 合格 / 待核 / 禁用

| 级别 | 定义 | 典型来源 | 处理方式 |
|---|---|---|---|
| **T0 一等·权威底本** | 精校点校、底本可信，**无需质疑真伪** | 百家学院 `chtxt` 精校库：`duan-dai-shi`（正史系列，211 篇）、`dong-shi-gong`（儒家十三经·诗经，2893 篇） | 优先采信；引用带四要素即可，不强制标疑 |
| **T1 二等·一手可读** | 公开可核验的一手，版本可靠 | 中华书局点校本二十四史 / 《资治通鉴》 / 《通鉴纪事本末》、历代会要、十通（通典·通志·文献通考）、经典方志（一统志·地方志）、已公布出土文献（睡虎地秦简·居延汉简·敦煌文书）、权威学术论文（核心刊·古籍整理专著） | 可用，带四要素 + 注明版本（如"中华书局点校本"），不强制标疑 |
| **T2 三等·待核/二手** | 有史料价值但版本或底本存疑 | `daizhigev20` 全量古籍、未核原典的整理本/注译本、版本存疑方志别史、网络可查但未复核者 | **必须显式降级**：标注「待核原典 / 据 XX 整理本」，不得与 T0/T1 混用或冒充精校；语气禁用定论 |
| **T3 不合格·禁用** | 非史料或不可信 | 演义小说当正史（如《三国演义》当三国史）、自媒体/营销号未核实内容、"历史冷知识/惊天揭秘"无出处爆料、AI 生成且无出处的"史料"、以今度古空谈、纯维基条目（仅作线索，须回溯原典） | **一律不引用**；若读者可能混淆，文中点明"此说出自演义/网传，非正史" |

**检索优先级（落到知识库/MCP）**：结果天然按 `chtxt`(T0) > `daizhigev20`(T2) > 其他 排序（见 `百家学院数据接线实测.md` §5 的 `sourceOrder`）。

---

## 2. 四要素引用格式（硬性）

**每处引用必带四要素**，缺任一要素 → 自动降为 T2 并标「待核」：

```
朝代(dynasty) / 作者(author) / 书名或篇名(title) / 出处(source)
```

- 正例：「据《东京梦华录》（宋·孟元老，chtxt 精校）记载……」
- 缺要素反例：「古人云……」（无朝代/作者/书名 → 须标「待核」或弃用）

---

## 3. 存疑处理协议（suspect handling）

1. **命中 T2/T3 或版本存疑** → 显式标注「存疑 / 待核原典 / 未见可靠史料记载」；
   禁用"确为""必定""可知"等断言语气；**不作文章立论主干**，只可作"有此一说，待考"。
2. **检索无结果** → 禁止编造，明说「未见可靠史料记载」，并给出可核查方向
   （如"建议查《XX》某志"）；必要时**建议人工核查**。
   （呼应治理护栏原则：历史考据官存疑必走人工闸——质量与合规双重兜底。）
3. **多源冲突** → 并列呈现各自出处与置信度，不下单一定论（除非 T0 精校可定）。
4. **T3 内容** → 不引用；若易与正史混淆，须点明其非史料性质。

---

## 4. 置信度映射（provenance.confidence 必填）

每篇文章 `provenance.confidence` 按所引最高级别来源填写；**多源混用取最低并如实标各源置信度**：

| 来源级别 | confidence 区间 |
|---|---|
| T0 `chtxt` 精校 | 0.90 – 0.95 |
| T1 点校 / 权威论文 | 0.75 – 0.90 |
| T2 待核 | 0.40 – 0.65 |
| T3 | 不引用（故不取值） |

## 5. 检索策略（落地到 Agent 行为）

- **首选（未来）**：百家学院经**标准 MCP 服务器**接入后，历史考据官默认检索 `duan-dai-shi` + `dong-shi-gong`（接口须留 `expertId` 配置项，默认 `[duan-dai-shi, dong-shi-gong]`，可扩充方志/实录），结果 `chtxt` 优先。
- **当前 fallback（DSH 预览版限制）**：百家学院检索工具暂不可加载，historian 以 `web_search` 核验权威一手（T1 可核验源）+ 自身研读作基底；**凡论断须 web_search 核验或明标「据既有研读，待核」**，引用仍须四要素。
- **知识库契约不变**：切换 MCP 时 `provenance` 字段（agent/model/sources/confidence）与本文口径保持不变，只换检索适配器，不重造。
